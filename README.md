# Employee CRUD using Hibernate XML Mapping

This project demonstrates CRUD operations using Hibernate
with XML-based mapping and MySQL.

## Technologies Used

- Java 17
- Hibernate ORM
- Maven
- MySQL
- Eclipse

## Features

- Create Employee
- Read Employee
- Update Employee
- Delete Employee
- Hibernate XML Mapping
- MySQL Database Integration

## Hibernate Concepts Used

- Configuration
- SessionFactory
- Session
- Transaction
- XML Mapping
- CRUD Operations

## Database Configuration

Before running the project, update the MySQL password
in `hibernate.cfg.xml`.

Replace:

`YOUR_PASSWORD`

with your local MySQL password.

## How to Run

1. Clone the repository.
2. Open the project in Eclipse.
3. Update Maven dependencies.
4. Configure MySQL credentials.
5. Run `App.java`.
